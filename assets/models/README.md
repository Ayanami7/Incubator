# 展示模型来源

## Avocado

- 来源：[Khronos glTF Sample Models — Avocado](https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/Avocado/glTF)。
- 制作：Microsoft；许可：CC0-1.0 Universal。
- 格式：glTF 2.0，附外部 `.bin` 和 PNG 纹理。

## Utah Teapot

- 模型原作：Martin Newell，University of Utah；参见 [Utah Teapot 官方页面](https://graphics.cs.utah.edu/teapot/)。
- 官方页面说明模型可用于包括商业用途在内的任何用途，并请求标明 Utah Teapot 名称及 University of Utah 来源。
- 当前文件为 OBJ，具体导出来源未留档。
