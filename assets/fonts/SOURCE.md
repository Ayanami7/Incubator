# 界面字体

字体为 Noto Sans SC Regular，来自 [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk/tree/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/SubsetOTF/SC)，固定修订 `f8d157532fbfaeda587e826d4cd5b21a49186f7c`。

原文件为 `Sans/SubsetOTF/SC/NotoSansSC-Regular.otf`，未修改字体；采用 SIL Open Font License 1.1，原始许可保存在 OFL.txt，并随字体部署。

当前使用 ImGui 的 ChineseSimplifiedCommon 字形范围：基本拉丁字符、相关标点、假名、全角字符及约 2500 个常用简体汉字。用于英文界面和常见中文路径，不承诺显示所有中文生僻字或完整 Unicode。
