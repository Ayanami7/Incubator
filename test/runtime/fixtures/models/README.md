# 模型导入精确夹具

`minimal_gltf/` 与 `minimal_obj/` 是本项目编写的精确测试样本，按 **CC0-1.0** 提供。
两种格式最终都解析到虚拟路径 `textures/direction_rgba.png`：glTF 使用相对 URI，OBJ 由 MTL 相对自身目录引用。
两张精确纹理及其像素约定见纹理夹具目录说明。
坐标为右手、Y-up，1 数值单位为 1 模型单位；不自动居中、换轴或缩放归一化。

## 几何与材质

- 左侧四边形：`(-1,.5,0), (-1,-.5,0), (0,-.5,0), (0,.5,0)`，三角形 `0,1,2 / 0,2,3`。
- 右侧三角形：`(.1,-.5,0), (1.1,-.5,0), (.6,.5,0)`，索引 `0,1,2`。
- 左侧 Direction 材质使用方向图、线性白色；右侧 Solid 材质无纹理，线性 RGB 为 `(.5,1,.5)`。
- glTF 左侧 UV 顺序为 `(0,0), (0,1), (1,1), (1,0)`；OBJ 的 vt 顺序为 `(0,1), (0,0), (1,0), (1,1)`。
  导入后，两者上边缘均对应 PNG 首行；采用既有 nearest/repeat、opaque、无剔除显示语义。

## glTF

`minimal_gltf/model.gltf` 使用外部 `geometry/mesh.bin`，按小端数值保存：

| 区间偏移 | 内容 | 字节数 |
|---|---|---|
| 0 | 四边形 position，4×float3 | 48 |
| 48 | 四边形 UV，4×float2 | 32 |
| 80 | 四边形索引，6×uint16 | 12 |
| 92 | 三角形 position，3×float3 | 36 |
| 128 | 三角形索引，3×uint16 | 6 |

一个 mesh 的两个 primitive 分别引用贴图与纯色材质。SourceRoot 为显式列主序矩阵 `T(.25,0,0)`，
其子 Parent 绕 Z 旋转 45°；Leaf 使用 `T(.1,.2,0)*S(.75,.5,1)`，Shared 使用 `T(0,-1.5,0)`，
二者都引用同一 mesh。导入后为两份几何、两个部分、四个节点，两叶节点共享几何引用；
Assimp 还会保留一份默认材质，准备层按使用情况选择材质。
Leaf 点 `(1,1,0)` 经根→父→子组合后为 `(.25+.15/√2, 1.55/√2, 0)`。

## OBJ

`minimal_obj/model.obj` 声明 `materials/model.mtl`，MTL 中的贴图相对其所在目录解析。
四边形由 Assimp 三角化，纯色三角形没有 UV。文件不编码额外节点变换；导入保留 Assimp 给出的源根与物体节点。

这些文件只供测试使用，由 `runtime_test_fixtures` 按显式依赖部署到独立测试资产根；
它们不进入 Demo 资产。CPU 测试仍复用真实 ModelLoader/ResourceManager 路径。
